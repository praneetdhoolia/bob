Research incorporation

CTM motivates testing useful recurrent computation while retaining live evidence; its task demonstrations do not prove sentience. Human unattended-memory recordings motivate interference and attention-switch controls. Bidirectional recurrent gating suggests training state-conditioned sensory selection rather than hand-assigning self/world fields. Primary sources are listed below; these are engineering hypotheses, not reproduced biological mechanisms.

The latest after-only visual controls establish a genuine interference effect with an unchanged query packet. Earlier throughout-video tests confounded memory and query position; they must not be described as pure forgetting. The trained internal-flow convergence failure prevents its deployment. The next meaningful research direction is label-free prediction and learned reliability from the same state, with audiovisual/code-feedback retention and learned-gate ablations. No new model is claimed implemented here.
