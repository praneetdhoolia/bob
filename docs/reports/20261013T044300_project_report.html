Research integration and optimization

CTM motivates tests of useful internal computation; its private neuron histories and synchronization are not implemented. V-JEPA motivates prediction without answer labels; the pooled native target here is different. Human working-memory evidence motivated separating cue layout from subsequent visual interference, not importing a consciousness claim. Indicator-based consciousness research is recorded as uncertain theory.

Existing shared-path prediction avoids a redundant untrained head and recurrent cache. Learning machinery remains parameter/optimizer state. Token targets are pooled, which can hide errors in a weak modality. Next optimization must improve temporal representation rather than disguising weak prediction by changing the scoring target.

Bounded compact events remove repeated full histories from each 100 ms sample. Actual bandwidth reduction has not been measured; expected savings scale with prior chat length. Validation must compare wire bytes on a long synthetic chat without dropping required output events.

The FIR worklet adds about 3 million multiply-accumulates per second at 48 kHz. This is an arithmetic estimate, not measured browser CPU time. Benchmark callback duration on live capture; reduce taps only if alias rejection and packet timing remain acceptable.
